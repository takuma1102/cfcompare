# Plot a TROP placebo test

Histogram of the placebo-null ATT distribution with the observed ATT
drawn as a solid reference line and zero as a dashed line.

## Usage

``` r
# S3 method for class 'trop_placebo_test'
autoplot(object, ...)
```

## Arguments

- object:

  A `trop_placebo_test` from
  [`trop_placebo_test()`](https://takuma1102.github.io/cfcompare/reference/trop_placebo_test.md).

- ...:

  Unused.

## Value

A ggplot2 object.
